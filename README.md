# DUO

iPhone・iPad向けの個人用英語学習PWAです。日本語UI・暗い青の背景と明るい白の半透明カードで、問題・履歴・設定・手書きの筆跡をIndexedDBに保存します。アカウント、学習データを送る外部API、自動同期はありません。DUO教材の例文・訳・単語は同梱していません。教材から読み取った内容は利用者が確認して登録してください。

## 開発・起動

Node.js 22.12以上（この環境では24.19.0）、npmを使用します。

```sh
cd /workspace/DUO
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

開発サーバーはHMR用で、Service Workerは登録しません。PWA・オフライン動作は必ず本番ビルドで確認します。

```sh
npm run build
npm run preview -- --port 4173 --strictPort
npm test
npm run test:e2e
```

E2Eはビルド済み `dist` を配信し、Chromiumでデスクトップ・スマートフォン・タブレットサイズを検証します。`/usr/bin/chromium` があれば自動で使用し、別の実行ファイルは `CHROMIUM_PATH` で指定できます。なければ `npx playwright install chromium` を実行してください。WebKitも実行する場合:

```sh
PLAYWRIGHT_BROWSERS_PATH=/workspace/.pw-browsers npx playwright install webkit
PLAYWRIGHT_BROWSERS_PATH=/workspace/.pw-browsers TEST_WEBKIT=1 npm run test:e2e
```

Linuxではブラウザのシステム依存パッケージが別途必要になる場合があります。ダウンロード先 `cdn.playwright.dev`（リダイレクト先を含む）のネットワーク許可が必要です。今回のクラウド環境ではダウンロードが403で拒否されたため、WebKit・Safari実機は未検証です。Chromiumの画面サイズ試験はSafariの互換性を保証するものではありません。

## 初回の使い方

1. 初回はオンラインでアプリを開きます。本番版で「オフライン準備完了」が出るまで待ちます。
2. 「データ」で1件ずつ登録、またはJSON/CSVをプレビューして登録します。「開発用の架空データを追加」は教材と無関係な4件を追加します。重複番号は追加しません。
3. 「学習」で例文／単語、英語→日本語／日本語→英語を選びます。セクション・例文番号・単語番号は `1-5,8` のように入力できます。空欄は全範囲、未登録範囲は対象外です。開始前に対象数を表示します。
4. 番号順／ランダム、全問／指定数、苦手／期限到来／お気に入り／要復習を選べます。苦手は選択方向の最新評価が「微妙」「覚えてない」の登録済み問題です。
5. 回答して正解候補と比較し、正誤と記憶を評価します。正誤と「覚えた・微妙・覚えてない」は独立です。英語の登録正解・別解との一致だけを自動判定し、意味の同一性を判断できない回答は「判断保留」を初期選択して自己判定に任せます。近いスペルは候補として知らせます。日本語も自己判定が基本で、登録別解を候補として表示します。
6. 「覚えてないとして記録し、その場で再挑戦」で前の回答を保存してやり直します。再挑戦が正解でも前の不正解履歴は残ります。スキップは未回答として「覚えてない」で保存します。
7. 「検索」は「例文モード」「単語モード」を切り替え、1セクション分を番号順の縦一覧で表示します。一覧部分を左右にスワイプするか、前へ／次へ・セクションボタンで移動します。番号・英語・日本語・登録別解の検索は選んだモードの全セクションが対象です。検索中は一致する項目があるセクションだけを移動します。未登録の範囲は飛ばし、一部しか登録していなくても利用できます。
   詳細画面でも左右のスワイプ、前へ／次へボタンで同じ種類の前後の問題を見られます。登録済みの番号順で、セクションをまたいで移動でき、先頭・末尾では止まります。「一覧へ」でモード・検索語・セクションに戻ります。詳細で前後に移動した場合は、その問題のセクションに戻ります（検索中は検索条件に合うセクションを優先）。トラックパッドの横スクロール・外付けキーボードの左右矢印にも対応します。入力中の左右矢印、縦スクロール、文字選択、ピンチ操作はページ移動に使いません。
   詳細画面でお気に入り・要復習を設定できます。「記録」で7日間の学習量、3段階評価の割合、例文／単語を分けたセクション別進捗と全回答履歴を確認できます。
8. 定期的に「データ」でJSONバックアップをファイルに保存します。

学習量・1日の目標は回答回数（再挑戦・スキップを含む）で集計します。結果には異なる問題の件数も表示します。復習予定は問題の種類・番号・出題方向別に管理し、「覚えた」の連続評価で設定日数の最大8倍まで伸ばします。復習間隔の変更は次の評価から反映され、既存の予定を遡って変更しません。

タイマーは有効な学習時間だけを計測します。ヒントは設定秒数から答えの先頭を1文字ずつ表示し、時間切れで正解候補・評価へ進みます。アプリや学習画面を離れた場合は停止し、戻って「再開」を押すまで進みません。Enterで回答確認、Shift+Enterで改行。IME変換中のEnterは送信しません。回答確定・評価ごとに履歴を保存しますが、未評価の入力・現在の問題位置はメモリ上です。再読み込みやOSの強制終了で途中のセッションを再開する機能は未実装です。保存済み回答は残ります。

画面の切り替えとセクション移動には短いフェードを付けています。iPhone・iPadの「設定」→「アクセシビリティ」→「動作」→「視差効果を減らす」などで動きを減らしている場合、フェードは無効になります。Safariの画面端のスワイプはブラウザの戻る／進むが優先されることがあるため、一覧・詳細の中央付近から操作するか、前へ／次へボタンを使ってください。モード・検索語・選択中のセクションはアプリを開いている間保持し、再読み込み後は初期表示に戻ります。新しいデザインが反映されない場合は、学習を記録し終えてからオンラインで開き、数秒待って再読み込みしてください。更新の取り込みと表示に2回の読み込みが必要な場合があります。サイトデータの削除は不要です。

## Apple Pencilと手書き回答

「学習設定」の「回答方法」で「手書き（Apple Pencil・指）」を選ぶと、専用の回答欄に書けます。対応するiPadとApple Pencilのほか、指・マウスも使えます。学習中も「キーボード」「手書き」を切り替えられ、その問題の下書きはそれぞれ保持します。回答の確認・記録には選択中の方法だけを使い、次の問題・再挑戦では白紙に戻します。

「ひとつ戻す」「すべて消す」で修正し、「回答を確認」で筆跡と正解候補を見比べて自己採点します。文字認識・自動採点は行いません。英語・日本語どちらにも使え、通信や追加料金は不要です。一時停止中は書けません。画面の向きや大きさが変わっても筆跡の比率を保ちます。

記憶を評価して記録した筆跡は、「記録」の回答履歴とJSONバックアップに含まれます。古い文字入力だけのバックアップも復元できます。手書きは座標と筆圧のデータとして保存し、1回答につき256画・合計20000点までです。上限では既存の筆跡を保持して案内し、戻す・消す・キーボードへの切り替えを使えます。書いている途中の未評価の下書きは、再読み込みやアプリ終了後に復元できません。

OSによる文字変換を使いたい場合は、対応するiPadとApple PencilでiPadOSの「スクリブル」を有効にし、「キーボード」の回答欄に書く方法もあります。対応言語・機能は端末とiPadOSの設定によります。Safari／ホーム画面版でのApple Pencil実機動作は未検証です。iPhoneはApple Pencilに対応しませんが、手書き欄には指で書けます。

## iPhone・iPadとオフライン確認

SafariでHTTPS配信のURLを開き、初回読み込み後、共有ボタン →「ホーム画面に追加」を選びます（OSでメニュー位置が異なります）。ホーム画面から起動できます。Safari 16以降を想定していますが、実機受け入れ試験は今後必要です。

「オフライン準備完了」後に機内モードにし、アプリを開き直してください。ホーム・検索・学習・結果・進捗を表示し、回答を評価してからもう一度開き直して履歴が残ることを確認します。初回読み込みはオンライン必須です。開発サーバーではオフライン準備をしないので、`build` + `preview` またはHTTPS配信版を使ってください。

IndexedDBの容量不足・保存拒否は日本語で通知します。保存に失敗した操作は画面上の確定データにも反映しません。別タブが保存していた場合は上書きを拒否し再読み込みを案内します。Safariのサイトデータ削除、プライベートブラウズ、OSによる容量整理はデータ消失の原因になります。永続保存リクエストが拒否されても利用できますが、バックアップは必要です。Safariタブとホーム画面アプリで保存領域の扱いがOSにより異なる可能性があるため、利用する起動方法で確認してください。

## 登録形式

JSONは問題オブジェクトの配列、または `{ "items": [...] }` を取り込みます。例（すべて開発用の架空データ）:

```json
[
  {
    "kind": "word",
    "number": 1,
    "section": 1,
    "en": "moon garden",
    "ja": "月の庭",
    "aliasesEn": ["lunar garden"],
    "aliasesJa": ["月面の庭"],
    "partOfSpeech": "名詞（架空表現）",
    "otherMeanings": "宇宙の庭（補足例）",
    "notes": "開発用であり教材データではありません。",
    "synonyms": "lunar garden",
    "related": ["moon gardener（番号なし・出題対象外）"],
    "favorite": false,
    "review": false
  }
]
```

必須: `kind` (`sentence` / `word`)、1以上の整数 `number`・`section`、空でない `en`・`ja`。番号は種類ごとに一意で、例文1と単語1は別の問題です。品詞、その他の意味、説明、類義語、番号なし関連表現は補足表示のみ。番号付き見出し語・熟語だけを独立した `word` として登録します。判定候補は主要な `ja` と `aliasesJa`、英語は `en` と `aliasesEn` です。補足の意味を勝手に正解候補にはしません。

CSVはUTF-8、1行目が列名です。配列欄は `|` 区切り、カンマ・改行・引用符を含む欄はCSVの引用符規則を使用します。

```csv
kind,number,section,en,ja,aliasesJa,partOfSpeech,notes
word,1,1,moon garden,月の庭,月面の庭|月の庭,名詞,開発用の架空データ
sentence,1,1,My robot grows blue tomatoes.,私のロボットは青いトマトを育てます。,,,開発用の架空例文
```

取り込み前に内容を表示し、番号重複・必須項目不足・形式エラーが1件でもあれば登録しません。既存問題の更新は一覧の詳細から「編集」を使ってください。種類・番号は記録との関連を守るため編集できません。一括登録は10000件・ファイル10MBまでです。大規模データの性能最適化は未実装です。

## バックアップと復元

バックアップは `version: 1`、`items`、`records`、`sessions`、`settings` を含むJSONです。形式と履歴を検証し、プレビュー後に確定します。

- **追加統合**: 同じ種類・番号の問題と設定は端末側を優先。未登録問題を追加し、復習記録は更新日時が新しいもの、履歴は未登録IDだけ追加します。
- **完全復元**: 現在の全データをバックアップの内容で置換します。プレビュー画面の確認チェックが必要です。先に現在のバックアップを保存してください。

復元を確定すると途中の学習は終了します。保存はIndexedDBの1トランザクションで行うため、保存失敗で一部だけ置き換わることはありません。バックアップに回答内容が含まれるため、ご自身で保管してください。復元ファイル上限は20MBです。

## 住所・支払い情報を追加登録しない自分専用サイト（準備済み）

GitHubのコードを非公開に保ち、Cloudflare Workers FreeとGitHubログインで本人だけに配信する構成です。Zero Trustの住所・支払い情報登録は使いません。独自ドメインなしでも使えます。サイトの入口でGitHubの本人IDを確認し、学習問題・回答・履歴は端末内に保存します。Workers Freeの契約を維持し、有料サービスは申し込みません。無料枠の上限では配信が止まり、認証を飛ばして公開することはありません。

[非公開サイトの設定・配信手順](docs/private-website.md)に、Workers Freeの確認、GitHub OAuth Appの設定、本人IDだけの許可、WorkerのSecret、配信方法、Safari・オフラインの受け入れ確認をまとめています。認証設定が未完了なら配信処理はファイルを返しません。

Cloudflareの**ビルド用**に `GITHUB_CLIENT_SECRET` を登録済みの場合は、デプロイコマンドを **`npm run deploy:private`** にします。登録済みの暗号化Secretを、値を表示・ファイル保存せず実行時のWorkerへ渡して配信します。ビルドコマンドは `npm run build` のままです。標準の `npx wrangler deploy` を使う場合は、ビルド用とは別の実行時Secretへの登録が必要です。

ログインに失敗した場合は、日本語の理由と `DUO-A01` などの確認コード、「もう一度GitHubでログイン」のリンクを表示します。Safariの同じタブでやり直してください。問い合わせには確認コードだけを使い、Secretや認証後のURLは送る必要がありません。コードごとの確認方法は[非公開サイトの手順](docs/private-website.md)を参照してください。

`DUO-A07` の原因となっていた、Workersでは未対応の `redirect: "error"` を修正しました。GitHubへの通信には `manual` を使い、リダイレクト先への通信を拒否します。実際のworkerdで認証の往復を試す `npm run test:oauth-runtime` を追加し、Node.jsのモックだけでは検出できなかった互換性を確認します。

```sh
npm run build
npm test
npm run cloudflare:check
npm run deploy:private -- --dry-run
```

`cloudflare:check` と `deploy:private -- --dry-run` はローカルでのWorkerビルド確認で、Web公開しません。後者もSecretを送信しません。利用者からGitHubログインとJSON登録の成功を確認しています。Safari実機のオフライン・ホーム画面起動・Apple Pencilは追加確認が必要です。GitHub Pagesの公開ワークフローは削除し、`.github/workflows/checks.yml` で検証だけを実行します。既存の `npm run test:pages` はサブディレクトリ・オフライン検証用として残しています。

URL・ドメインが変わる場合は、移行前にJSONバックアップを保存して移行先で復元してください。オフライン保存済みのデータは、その端末を利用できる人には見られるため端末のロックも利用してください。
