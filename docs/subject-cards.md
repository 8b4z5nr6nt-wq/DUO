# 国語・歴史総合のカード教材

科目選択で「国」または「歴」を開き、「JSONを取り込む」からファイルを選びます。JSONが書かれた `.json` や `.txt` を選ぶと、取り込み前の確認が開きます。貼り付けた場合は「取り込み前に確認」を押してください。内容を確認して登録し、科目のホームからカード学習を始めます。「JSONのひな形」から入力用のファイルを保存できます。

国語は `subject` を `ja` にします。各カードの `deck` は現代文単語なら `modern`、古文単語なら `classical` です。

```json
{
  "format": "subject-cards",
  "version": 1,
  "subject": "ja",
  "cards": [
    { "deck": "modern", "number": 1, "question": "現代文の見出し語", "answer": "意味を入力" },
    { "deck": "classical", "number": 1, "question": "古文の見出し語", "answer": "意味を入力" }
  ]
}
```

歴史総合は `subject` を `history` にします。`deck` は省略できます。

[6分類のJSON Schema](../schemas/history-cards.schema.json)と[取り込み用の見本](../examples/history-cards.example.json)を用意しています。

```json
{
  "format": "subject-cards",
  "version": 1,
  "subject": "history",
  "cards": [
    { "number": 1, "question": "出来事についての問い", "answer": "答えを入力", "category": "event" }
  ]
}
```

`number` は1以上の整数、`question` と `answer` は空欄にできません。同じ `deck`・番号のカードは更新され、評価や学習履歴は引き継がれます。1ファイル10MB、1科目10,000枚まで取り込めます。

カード面をタップするか「カードをめくる」を押すと答えを表示します。ボタンか左右スワイプで評価します。右は「覚えた」、左は「覚えていない」です。評価と教材は科目別に端末へ保存されます。オフライン準備完了後は通信なしで使えます。取り込んだ元のJSONは保管しておくと、別の端末でも教材を登録できます。

歴史総合では `category` に `era`（年代）、`person`（人物）、`event`（出来事）、`term`（用語）、`other`（その他）、`uncategorized`（未分類）を指定できます。省略した新規カードは未分類です。更新時に省略すると登録済みの分類を引き継ぎます。検索結果からカードを開いて分類を変更することもできます。

## 歴史総合のメニュー

- 「学習」で分類、番号の範囲、苦手・未学習の絞り込み、出題順、問題数を選べます。
- 「検索」は番号・問題文・答えに対応します。分類ごとの該当件数が表示され、タップすると絞り込めます。
- 「記録」では最新の評価と直近7日間の学習量を確認できます。更新前の評価も習得状況に含まれます。
- 「設定」で1日の学習目標を変更できます。
- 「データ」で教材を取り込み、教材・評価・履歴・設定をまとめて保存できます。保存したファイルを同じ画面で選び、「バックアップを追加統合」を押すと復元します。登録済みの同じ番号のカード・評価と、保存済みの設定は端末側を優先します。
