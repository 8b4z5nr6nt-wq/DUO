# 教材JSON入力仕様 v1

`examples/materials-fictional.json` は全て架空の例です。教材の推測・転載はありません。
機械仕様: `schemas/materials.schema.json`。形式は `format: "duo-materials"`, `version: 1`。

```json
{"format":"duo-materials","version":1,"sections":[{"number":1,"sentences":[{"number":1,"en":"My robot painted a tiny moon.","ja":"私のロボットは小さな月を描きました。","words":[{"number":1,"en":"paint","ja":"描く","related":[{"en":"moon painter","ja":"月の絵描き"}]}]}]}]}
```

- section.numberはセクション番号、sentence.numberは印刷された例文番号、word.numberは印刷された単語番号。全て1以上の整数です。例文番号と単語番号はそれぞれ教材全体で一意です。
- wordsは任意。単語は対応する例文のwordsに配置します。単語自身へセクション・例文番号を重ねて入力する必要はありません。
- enは青文字の見出しをそのまま入力します。構文・熟語の構成要素も保持します。例文のpaintedからpaintを自動生成する処理はありません。実教材の青文字かどうかは人が確認し、不明なら登録しません。
- jaは主要な意味を1つ、例文は対応する訳を入力します。必須文字列は空欄不可。前後の空白以外は変更しません。
- 同じ英語表現でも印刷番号が異なれば別の問題として保持します。同じ単語番号を別の例文に重複登録することはできません。
- relatedは任意の英語・日本語の組です。親の識別子word:番号へ暗黙に紐づきます。旧形式のrelated文字列配列も残ります。新関連語はrelatedWordsへ保存し、検索・詳細に表示します。通常の問題配列に展開せず、問題数・習得率・復習には含めません。将来の出題は別の識別子体系を追加して拡張できます。
- 同じファイルの重複、未知の項目、型違い、対応関係の矛盾は拒否します。1ファイル10MB、例文・単語合計10000問までです。

## iPhone・iPadで登録

PrivateのDUO-DataからJSONを「ファイル」へダウンロードします。アプリの「データ」→「教材JSONの手動インポート」でファイルを選び、登録方法を選んでプレビューし、確定します。アプリはGitHubへアクセスせず、教材を自動送信しません。
「追加」は既存番号の重複で全体を中止。「追加・更新」は同じ種類・番号の教材を更新し、無い番号を追加します。省略した既存問題は削除しません。お気に入り・要復習・回答履歴・復習予定・設定は保持します。新形式のrelatedを省略して更新すると、その単語の新形式の関連語を空にします。旧形式の補足・別解は明示更新しなければ保持します。

既存の平坦なJSON配列とitemsラッパーは引き続き使用できます。新形式は内部で既存のsentence/word配列に変換します。旧問題へ対応例文を付ける場合は、同じ印刷番号で新形式を更新登録してください。番号を変更すると履歴の別問題になるため変更しないでください。

CSVと個別編集は既存機能の削除禁止に従って互換用に残しています。新しい教材運用は手動JSONへ統一します。
登録はIndexedDBの1トランザクションで確定します。不正データ・保存失敗時は変更を反映しません。定期的に全データJSONバックアップを保存してください。バックアップには教材も含まれるためPublicへ置かないでください。

## カード上で単語をタップして例文の部分訳を表示する

単語の基本必須項目は従来どおりnumber・en・jaです。カードのタップ表示には、次の任意項目を追加します。

- sentenceForm：例文中の使用形。見出しと一致する場合は省略可。見出しen自体を書き換えません。
- sentenceTranslation：対応する例文の日本語訳から、その単語・熟語に対応する部分をそのまま抜き出した文字列。

例えば架空の英文「The robot painted a moon.」と訳「ロボットが月を描いた。」のwordsに、見出しen=paint、ja=描く、sentenceForm=painted、sentenceTranslation=描いたを登録すると、カード上のpaintedをタップして「描いた」だけを表示できます。単語は対応例文のwords内に配置します。例文内訳が未登録ならタップ対象にせず、語義から機械的に推測しません。登録された例文にない使用形・訳はインポート時に拒否します。

DUO-Dataの例文専用スキーマはwordsを許可しません。単語も含む教材へ拡張するときは、対象のsentences-*.jsonをmaterials-*.jsonへ変更して共通教材スキーマを使い、同じ例文番号を複数のファイルへ重複保存しないでください。既存番号で追加・更新すれば履歴を保持できます。
